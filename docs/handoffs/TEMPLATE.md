# 跨模块任务单模板

- Status: `active` / `completed` / `superseded`
- Owner: 负责人
- Priority: P0 / P1 / P2
- Scope: 涉及的模块和公共边界
- Supersedes: 被替代的任务单或规范；没有则写“无”

## 当前要求

说明本轮必须优先完成的目标和已确认的决策。

## 非目标

列出本轮明确禁止实现、推断或扩大范围的内容。

## 交付物

列出需要交付的设计、代码、测试、文档或审批节点。

## 验收条件

列出可验证的完成条件，以及必须由谁确认的决策。

## 依赖资料

列出当前任务必须阅读的代码、规范、计划和变更记录。

## 结束处理

完成或替代时，将本文件移入 `docs/handoffs/completed/`，保留文件名并更新 Status、
结束日期和后继任务单链接。
