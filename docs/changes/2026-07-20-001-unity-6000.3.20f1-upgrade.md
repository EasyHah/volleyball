## 改动摘要

把唯一 Unity 工程从 `6000.0.43f1` 升级并锁定到 `6000.3.20f1`，作为首个 Career 技术里程碑的共同
开发基线。升级只接受 Editor 自动生成的版本、包锁和项目设置 schema/default 变化，同时更新当前开发
说明；不引入 URP、Input System、NavMesh、玩法、Shared 契约或资源批量整理。

## 具体变更

- `ProjectSettings/ProjectVersion.txt` 锁定 `6000.3.20f1 (c9ba695d4f07)`。
- Unity Package Manager 自动完成以下兼容升级：
  - `com.unity.nuget.newtonsoft-json`：`3.2.1 -> 3.2.2`；
  - `com.unity.test-framework`：registry `1.1.33 ->` built-in `1.6.0`；
  - `com.unity.ext.nunit` 解析为 built-in `2.0.5`；
  - 新 Editor 为保持内置模块可用性，将 `adaptiveperformance`、`vectorgraphics` 及其依赖写入 manifest/lock。
- `ProjectSettings.asset` 接受 6.3 自动增加的序列化字段和新平台默认值；Windows 图形 API 被显式迁移为
  D3D11、D3D12 顺序且关闭自动选择。没有在本分支调整玩法、质量级别或场景内容。
- README 与开发命令改为使用 `6000.3.20f1`，并明确当前两个物理比赛场景仍是全 AI 沙盒。

## 回滚与风险

主要风险是 6.3 自动更新的包版本、ProjectSettings 新默认值以及 Windows D3D11/D3D12 显式顺序在另一台
开发机产生不同序列化结果。合并前必须比较干净导入后的 diff；不允许通过手工删除未知字段伪造旧格式。
若升级出现不可接受回归，整体回滚本变更并用 `6000.0.43f1` 重新生成 Library，不得只回滚
`ProjectVersion.txt` 后继续使用 6.3 保存资源。
